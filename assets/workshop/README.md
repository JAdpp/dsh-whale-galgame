当前运行的公共区、高清工作区、主题宿舍、角色、两张行走关键帧、专属工位和室外装饰共八张图，均由 Codex 内置绘图制作；工具未暴露具体模型版本，不将其标为 Image 2.6 产物。生成提示保存在 [`generation-prompts.json`](generation-prompts.json)，实际来源、生成记录、尺寸与 SHA-256 保存在 [`manifest.json`](manifest.json)。

PNG 保留为母版，客户端 bundle 内嵌同名 WebP 派生文件：房间图集使用有损质量 92，角色、工位与装饰图集使用近无损压缩，尺寸保持不变。需要重新生成时，先运行 `npm i --no-save sharp`，再运行 `node scripts/convert-workshop-art.mjs`，随后更新清单中的哈希；`runtime` 记录 WebP 文件与哈希，原有 `file`、尺寸与 `sha256` 仍描述 PNG 母版。

原始 `manor-atlas-image26.png`（3072 × 2048）和最初的繁复 Logo 来自 GPT Image 2.6 Sunburst，均已被替换，不再作为当前运行素材内嵌。原庄园图保留在 Git 源码中，旧图的提示、生成记录与哈希保留在清单中，供追溯与重建历史版本；它们不代表当前地图或 Logo 的生成来源。

## 渲染与动画

原始 PNG 保持生成分辨率，角色、工位、室外装饰与 Logo 保留透明通道。行走时按完整图格截取，不裁掉翅膀、角、尾巴或工具；清单中记录各动作的脚点，将不同姿势对齐到同一地面。行走人物实际显示约 64–75 × 90 像素，地图画布使用 2 倍像素缓冲；人物画布按图集图格尺寸设置缓冲，再由 CSS 缩放。行走是四步循环：一只脚落地、并腿过渡、另一只脚落地、并腿过渡。向下用正面帧（过渡用待机帧），向左右用侧身帧（向左为镜像），向上用背影帧，停下时转回正面。转换脚本为每格记录锚点：纵向取脚底，横向取头部中线，这样迈步时身体不会左右晃；侧身图的人物比其他图小，绘制时按清单里的比例放大对齐。入座工作时改为完整的 144 × 144 专属工位帧，与行走人物同一比例，人物在桌后，桌面遮住下半身。

导航使用 48px 正交网格。主题宿舍、茶水休息室和海底观景室均以完整的新房间背景呈现，保留家具与建筑细节；公共办公区也使用完整重绘的室内背景，包含书架、长柜、窗户与仪器，再布置专属工位。整张地图画成深海中的一栋建筑：宿舍排成一排，门都开向同一条主回廊，回廊下方是居中的工作区，茶水休息室和海底观景室分列两侧。外墙、黄铜包边、回廊北墙的护墙板、长地毯和深海底色由代码按 2px 单位绘制，不占用图集。装饰全部靠回廊北墙摆放，而不是沿边等距摆放：相邻宿舍之间的墙垛前各一盏落地灯，宿舍一排两侧的空墙前分别是休息角（盆栽、长凳、落地灯）和书架角（落地灯、书柜、天球仪），每件家具带接地投影。整组场景放不下时整组省略，所有装饰避开门口和行走路线。

场景内不显示房名或人物姓名。侧栏“工坊里的她们”保留角色名单、工作状态和选择入口；点击场景中的角色形象也仍可进入对话。所有路线穿门通行并避开桌子阻挡范围，工位路线脚点位于桌南侧地面。角色抵达该点后才切入座动画。

办公循环分别为：鲸鱼娘调整潮汐仪并推演水纹，Claude 羽笔校稿和翻页，GPT 使用圆规与计划卡制图，Gemini 调整双棱镜，Kimi 整理月卷与书签，Grok 用工具检修小机械。三帧改变对应手部、工具与页面状态，桌椅在各帧中保持同一位置；等待确认使用单独静止帧。空工位和入座帧共用同一组图格位置。

宿舍按 Harness 中已接入且配置可用的模型系列动态拼接：只接入 DeepSeek 就只显示她的一间宿舍，同系列的多个版本共用同一角色。未接入的角色不占房间；所有宿舍排成一排并居中，接入的模型越多这一排越长。公共区域使用四格新背景图集，当前地图没有温室入口；旧六格原图里的温室属于历史素材。

`npm run embed:art` 校验八张 PNG 母版的尺寸与哈希，以及 WebP 派生文件的哈希、相同尺寸和无非视觉元数据，再校验动作网格与脚点，并生成 `src/client/workshop.generated.ts`，随后由构建过程内嵌 WebP 到客户端。npm 发布包不重复携带 PNG 或 WebP 图集，也不内嵌已替换的 Image 2.6 原图；Git 源码保留新旧原图与当前 WebP 派生文件以支持重建。打开地图、闲逛和切换动作不会调用图像模型或产生生成费用。
