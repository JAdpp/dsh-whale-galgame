# v0.8.0 · 深海工坊地图与主题美术

新增 Galgame 顶栏的“工坊地图”。宿舍数量跟随 Harness 已接入的模型系列，六位模型娘各有一间参考对应视觉小说背景设计的像素宿舍。公共区包含协作工坊、茶水休息室、海底观景室与回廊，采用完整家具与明亮庄园陈设。

- 工作状态跟随实际调用的模型，包括其他工作区与子 Agent；角色工作时前往工位，空闲时回房或散步，点击可进入她的对话。
- 六位角色各有坐在桌后的专属办公动画；地图支持滚动、放大、暂停和系统减少动态效果。
- 简约鲸尾与星光 Logo 放在四种语言 README 的最开头，地图预览与素材来源说明同步更新。
- 顶栏“个性化”统一收纳背景图、角色立绘与角色设定。

当前四张地图与角色图集、Logo 均由 Codex 内置绘图生成，具体模型版本未暴露。素材、生成提示与历史 Image 2.6 记录见[庄园美术说明](../../assets/workshop/README.md)。打开地图和播放动画不会调用绘图模型。

原有角色存档、好感度、对话历史与自定义图片继续保留。

源码安装使用 `prepare` 构建；npm 安装包已内嵌全部运行美术，不重复携带原始图集。
