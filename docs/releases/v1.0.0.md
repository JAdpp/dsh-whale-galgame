# v1.0.0 · 正式版

dsh-whale-galgame 的第一个正式版本。功能与 0.10.0 相同，修复了插件无法通过市场升级的问题。

## 修复

- 修复插件市场更新反复失败并回滚的问题（[#20](https://github.com/JAdpp/dsh-whale-galgame/issues/20)）。以前插件卸载、热重载或市场更新时，`/whale-galgame-api` 路由没有注销，重新加载时报 `duplicate prefix route`，插件无法启用，市场便回滚到旧版本。现在卸载时会注销路由；热挂载与已安装版本同时存在时共用一个路由，最后一份卸载时才注销。
- 从旧版本在 DSH 不重启的情况下升级时，会接管旧版本遗留的路由，不再报错。

## 升级说明

- 0.10.0 及更早版本自身不会注销路由。如果从这些版本升级后插件仍未启用，重启一次 DeepSeek Harness 即可。
- 角色存档、好感度、对话历史与自定义图片继续保留。

感谢 @closedtimelikecurve 详细的排查与修复方案。
