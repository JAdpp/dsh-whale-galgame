# Project logo

[`logo-simple.png`](logo-simple.png) is the current 1254 × 1254 transparent project mark, generated with **Codex's built-in image generator** on 2026-11-12 after the user approved that route. The tool does not expose its exact model version. Its blue whale-tail silhouette suggests an open book, with one small golden star as the only secondary element.

The four README editions display the self-contained PNG at 160 × 160 pixels. It requires no external fonts or network resources. It was checked on white and deep-blue backgrounds at 32, 64 and 192 pixels. Both the earlier hand-drawn SVG and the ornate Image 2.6 draft are superseded.

The prompts, generation provenance, dimensions and SHA-256 are recorded in [`assets/workshop`](../../assets/workshop/README.md), including the earlier Image 2.6 draft's provenance. The mark does not incorporate a model company's logo. The artwork follows the project's license boundary in [LICENSE.md](../../LICENSE.md).
