# 数据与隐私

## 本地存储与迁移

运行时存档为 JSON，分为全局状态和工作区标记，两者都属于私人数据。

- `DSH_HOME/storages/dsh-whale-galgame/global.json` 保存完整、连续的 Galgame 状态：当前角色；六位角色各自的关系进度、角色设定、对话历史、当前回复选项、已消费任务记忆、自定义立绘与 CG 图鉴；背景、全局任务事件队列、token 结算余额、去重指纹和插件偏好。小剧场记录也保存在全局状态中。
- 当前工作区根目录的 `.whale-girl-save.json` 只保留轻量的事件来源与旧存档迁移标记，不再保存一套独立的剧情、聊天、任务记忆或 token 账本。
- 进入新工作区时直接沿用当前角色、对话历史、回复选项和关系进度。工作区或会话用于定位 Harness 事件来源与采集去重，不触发剧情重开或跨工作区拒绝页。同一 `DSH_HOME` 下的 Web 与 Desktop 共用全局存档。
- 首次打开旧版 v9 工作区存档时，插件自动把可迁移的剧情与角色数据合并到全局文件，并将该工作区的 `.whale-girl-save.json` 改写为来源/迁移标记。
- 文字速度与显示设置另存于当前浏览器或 Desktop 页面环境的 `localStorage`，键为 `whg-text-speed` 和 `whg-display-settings`。

用户上传的背景和立绘以图片数据保存在全局存档中；生成的 CG 也保存在本地。插件停用或卸载不会作为清除存档的操作。

## Harness 中读取的内容

任务感知在本地使用真人明确提交的 `user/message` 正文进行固定类别分类，可参考工具名与轮次结束状态。它不打开工作区文件读取内容，不提取工具参数、工具结果或 assistant 正文。具体会话范围与扫描规则见[机制说明](mechanics.md#harness-任务事件)。

原始 Harness 文本不写入 Galgame 存档。任务相关的持久化信息为固定类别与状态线索、匿名去重指纹和最近提及时间，供跨工作区去重与控制提及频率使用。token 结算另读取插件运行期间新观察到的 Harness `assistant/message` usage 数值，插件自身模型调用不计入。

深海工坊地图另外读取当前进程内的实时会话、Agent 运行状态、请求模型路由及提问/审批事件的控制字段，包含其他工作区和子 Agent，用于将角色放到工位或休息区域。地图接口只返回角色 ID、昵称、空闲/工作/等待状态、活跃任务数与更新时间；不返回会话 ID、工作区路径、消息正文或工具参数。地图不会查询持久会话历史、调用外部模型或保存闲逛位置；浏览器隐藏地图时暂停状态查询和动画。

自适应宿舍会在后台读取已注册提供商的可对话模型目录，并在 Harness 提供相应能力时读取脱敏配置与凭据的 `configured` 布尔描述，排除明确未配置的路由。它不解析或读取密钥值、不发送验证请求；目录故障保留此前已确认的住户。地图接口额外返回可出场角色的 ID、昵称和目录是否就绪，不将模型目录、提供商设置或凭据描述发给浏览器。

## 发送到外部服务的内容

### 对话模型

普通对话发送到 Galgame 当前选择的 DSH 模型提供商，包括用户在 Galgame 中输入的消息、用于延续对话的历史、角色设定、关系进度、本地日期与距上次对话的时间提示。Harness 工作上下文只发送固定的类别与状态提示，不附带其原文或工作区文件内容。

小剧场生成同样使用所选模型，提供出场角色设定、剧情情境和任务类别；使用联网素材时，还提供检索结果整理出的摘要与来源线索。

### 小剧场联网取材

联网取材默认开启，通过 DSH 的 web 能力检索。检索词只由角色对应的模型名与题材词构成，不包含用户的对话内容、工作区内容或任何 Harness 原文。

检索结果只用于本次小剧场生成；摘要与来源链接写入小剧场记录，网页正文不落盘。在“设置 → 插件 → 鲸鱼娘 → 小剧场取材”中选择“只用本地任务类别”可关闭这类检索。该选项只关闭联网取材；普通对话、小剧场文本生成及用户启用的 CG 仍会调用相应服务。

### DashScope 图像生成

生成升级 CG 时，插件把角色外观描述、等级、场景及固定任务类别的视觉提示作为文本发到 DashScope。生成小剧场合影时，发送角色外观描述与该场小剧场的情境；合影由用户手动点击触发。

用户上传的背景和立绘保存在本地全局存档中，不随对话、联网取材或 CG 请求发送。CG 请求不上传这些图片，角色外观来自文本设定。

## Git 工作区中的存档

本仓库的 `.gitignore` 只作用于本仓库。其他使用插件的 Git 工作区应在各自的 `.gitignore` 中加入：

~~~gitignore
.whale-girl-save.json
.whale-girl-save.*.json
~~~

这也覆盖可能含有旧数据的存档副本。真实 API key 保留在本地环境变量中，不写入仓库文件或提交到 Git。

## 清除数据

1. 退出使用同一 `DSH_HOME` 的 DSH Web 与 Desktop，避免内存中的状态再次写回。
2. 删除 `DSH_HOME/storages/dsh-whale-galgame/global.json`，以及各个使用过的工作区中的 `.whale-girl-save.json` 和 `.whale-girl-save.*.json` 存档副本。仍保留的旧版存档可能在之后被再次迁入。
3. 在使用过的浏览器或 Desktop 页面环境中，删除插件的 `localStorage` 键 `whg-text-speed` 与 `whg-display-settings`，以清除文字速度和显示偏好。

Galgame 顶栏的“重新开始”只把所有角色的等级与好感度重置为 Lv.1、0 点，保留对话、任务上下文、角色设定、图片及其他存档内容。清除上述插件数据不删除 Harness 自身的会话，也不撤回已经发给外部服务的请求。
