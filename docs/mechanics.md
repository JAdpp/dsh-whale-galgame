# 机制与详细设置

日常安装与操作见 [README](../README.md)，数据流向与清除方式见[数据与隐私](privacy.md)。本文保留关系进度、任务感知、角色设定和 CG 的具体规则。

## 好感度与关系进度

每个角色都从 Lv.1、0 点好感开始，状态彼此独立。亲近、普通、疏离三个回复选项分别结算 +1、0、-1，位置每轮随机；也可以自由输入，由轻量关键词规则结算。

插件运行期间，从所有工作区新观察到的 Harness `assistant/message` usage 事件会进入同一份全局 token 余额。输入与输出 token 每累计 5,000 个，结算时当前角色增加 1 点；每次结算最多兑换 3 点，余量继续保留。插件自身发起的模型调用不计入，也不回算插件启动前的历史 usage。

未活动的前 24 小时为宽限期，之后所有角色按每天 2 点衰减，最低为 0。实现按 `floor((未活动天数 - 1) × 2)` 计算本次衰减，并更新全局活动时间；关系活动时间采用 6 小时间隔的心跳更新，避免不同工作区重复结算同一段离开时间。

升级阈值为 `30 + 15 × (Lv - 1)`，即 30、45、60……。达到阈值后升级，超出部分保留到下一级，等级不设上限。角色语气随关系进度分为五档，Lv.5 后保持最高亲昵档。

普通对话的升级会尝试生成特殊 CG，成功生成需要可用的 DashScope key。小剧场结算中的升级会保留等级变化，但跳过自动 CG；该场合影由用户从小剧场记录中手动生成。

## Harness 任务事件

插件按事件来源的工作区采集顶层 Harness 会话，排除子 Agent 会话与继承的历史事件。优先读取实时会话；查询已保存会话时，最多选取 16 个候选，优先当前绑定会话，其余按创建时间排序。每个会话只扫描末尾 240 条事件，任务分类结果仅保留最近 72 小时的活动。

这里的 16 是已保存会话查询的候选上限；实时会话遍历没有同样的数量限制。72 小时限制应用于任务轮次的活动时间，并非只读取最近 72 小时内创建的会话。

本地、确定性规则将任务归为代码调试、代码开发、文档总结、文档写作、文学创作、资料调研、数据分析、视觉设计、演示文稿、翻译校对或任务规划，再将分类结果合并到全局事件队列。本地文本分类只使用真人明确提交的 `user/message` 正文，可参考工具名与轮次结束状态；不提取工具参数、工具结果或 assistant 正文，也不打开工作区文件读取内容。

只有固定的任务类别与状态提示会作为 Harness 工作上下文发给 Galgame 回复模型和 CG 生成服务。模型娘在回应当前话题时可以自然带到一句关心，例如代码调试后提醒主人不要熬夜。每个角色的已消费事件指纹与最近提及时间保存在全局状态中：同一事件不会因切换工作区而再次向同一角色主动提起，不同事件之间至少间隔 30 分钟。任务事件只影响话题，不直接增减好感度。

普通对话和小剧场还会获得本地日期、时段及距离上次对话的时间提示。时间间隔优先来自该角色的对话时间戳，缺少时参考记录的上次活动时间。

## 角色、模型与存档连续性

显示角色与回复模型分别选择。角色可以跟随工作区模型或手动固定；回复可以使用插件默认的 `deepseek-v4-flash`、跟随工作区，或从 DSH 模型目录选择。

六个角色各自保存好感度、等级、角色设定、聊天记录、回复选项、已消费任务记忆、自定义立绘与 CG 图鉴，并在工作区之间全局共享。当前角色、token 结算余额与插件偏好也连续保留。新工作区沿用这些状态，工作区和会话仅用于定位事件来源与采集去重。

### 自定义角色设定

在 Galgame 顶栏点击“角色立绘”旁的“角色设定”，编辑当前角色的昵称、对用户的称呼、首次问候、性格、语气和 CG 外观描述。

“保存设定”或“恢复默认”只修改当前角色的上述六项，不重置好感度与等级、长期记忆或自定义立绘。若该角色尚未开始真实对话，修改或恢复“首次问候”会原位更新当前开场问候，自动生成的登场旁白保持不变；一旦已有用户或角色对话，就不再插入、替换或重播历史。CG 外观描述用于之后生成的 CG，不改写图鉴中已经保存的图片。

自定义设定仍受插件的安全约束与单句回复限制约束。

### 内置角色风格

克洛德（Claude）是细心较真的书虫审校者，小吉（GPT）是自信傲娇、爱整理要点的远古白龙娘，洛可（Grok）是嘴快护主、爱玩宇宙梗的吸血鬼小公主。三人默认称呼用户为“主人”，并有各自在工坊里的同伴关系；称呼和风格可以通过角色设定修改。

## 舞台、图片与显示设置

台词有慢、中、快、瞬间四档打字速度。点击台词或按 Space / Enter 可补全整句；小剧场中整句显示后再次操作推进下一句。等待回复时先显示用户刚说的话，并显示角色“正在回应”的提示。在对话框上向上滚动可打开记录，回看角色台词及当时的表情。

按 H 或在背景、立绘处右键可隐藏界面，点击任意处或按 H / Esc 恢复。齿轮中的“显示设置”可选择文艺或系统字体，控制氛围特效、音效、BGM 和音量。文艺字体使用本机已安装字体；音效和 BGM 由 Web Audio 合成，默认均关闭。

背景与立绘换图时交叉淡入，新角色从下方滑入，立绘带有待机呼吸动画。表情根据角色自己的回复判断，没有表情差分时使用情绪气泡与动作。小剧场中说话的角色会轻跳，名牌带有指向角色的小尾巴；好感变化时飘出“♡±N”，升级时播放全屏演出。对话框使用黄铜与深海风格及角色专属强调色，背景有粒子与水纹光影，矮窗口和窄屏下会为角色的脸留出空间。

背景和立绘支持 PNG、JPEG、WebP、AVIF，浏览器端单个文件上限为 12 MB。切换角色时同步切换对应内置背景：鲸鱼娘默认使用 `palace-night.webp` 深海宫殿，海边书房是内置可选替代；其余五位使用各自背景。用户上传的背景或保存为背景的 CG 是全局覆盖项，直到恢复内置背景。

桌宠已内置，新安装默认开启，显示在 DSH 主界面右下角，点击即可打开 `galgame` 标签页。顶栏和插件设置中的桌宠开关保持同步。关闭“启用插件”会隐藏桌宠并暂停对话与好感度结算，存档保留。Desktop 的窗口覆盖层会避让 Windows 自绘标题栏与 macOS 红绿灯按钮。

## 小剧场与 CG

小剧场提供角色间日常短剧、工作事件复盘与里程碑剧情，完成的片段归档到“小剧场”记录中，可回看台词。联网取材默认开启；在“设置 → 插件 → 鲸鱼娘 → 小剧场取材”中选择“只用本地任务类别”可关闭检索。剧情生成仍通过所选模型进行，详见[数据与隐私](privacy.md)。

升级 CG 默认通过 DashScope 的 `qwen-image-3.0` 生成，尺寸为 1920 × 1080。提示由角色 CG 外观描述、升级等级、场景与固定任务类别的视觉线索组成。小剧场合影使用出场角色的外观描述与该场情境，由用户从记录中点击触发。

图像请求只发送文本提示，不上传用户背景或立绘。返回的图片下载为 data URL，连同生成提示、状态及错误信息存入 CG 记录。图鉴可查看图片，也可以将其设为 Galgame 背景。没有可用 key 时，聊天、角色切换、历史、好感度和自定义图片仍可使用。

在启动 DSH 的本地环境中设置 `DASHSCOPE_API_KEY`；环境变量示例见 [README 的使用说明](../README.md#使用)。真实 key 留在本地环境中。

## 美术清单与构建说明

安装包内嵌 22 项美术：六张角色立绘、七张内置背景、八张原始分辨率透明 `whale-*.webp` 表情，以及一张 8 列 × 11 行的 `pet-spritesheet.webp` 桌宠动画图集。逐文件用途、来源、改动与桌宠图集 SHA-256 保留在[美术清单](../assets/default/README.md)和 [NOTICE](../NOTICE.md)，许可索引见[第三方许可](../THIRD_PARTY_LICENSES.md)。

npm 包只携带内嵌美术的客户端 bundle，不重复收录导出原图或生成图源码。Galgame 布局、对话框、控件与装饰的实现公开在 `src/client/index.ts`，没有额外的未公开 UI 图片包。

`lib/` 与 `src/client/art.generated.ts` 是不提交的构建产物。`prepare` 在源码安装时运行 `npm run embed:art` 和 `tsdown`；克隆后执行 `npm install` 可在本地生成。`npm run sanitize:backgrounds` 剥离六张角色背景的非画面 WebP 元数据，`npm run embed:art` 将白名单原图写入运行时，`npm run export:art` 反向导出 22 项运行时美术以供核对。
