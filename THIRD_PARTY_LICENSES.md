## @linxin666/dsh-pet in dsh-web-ui

- Upstream distribution: [dsh-web-ui](https://github.com/zhu1090093659/dsh-web-ui)
- Preserved bundled license: [`assets/default/licenses/dsh-pet-LICENSE.txt`](assets/default/licenses/dsh-pet-LICENSE.txt)
- Bundled license text: BSD 3-Clause

`dsh-pet` was consulted as an implementation reference for pet state animation, click interaction, and DSH integration. It did not provide this project's current whale-girl sprite atlas.

The package metadata observed during integration names Apache-2.0, while the package's bundled `LICENSE` file is BSD 3-Clause. This repository records that discrepancy without attempting to resolve it and relies on the preserved bundled `LICENSE` text for this notice. Nothing here implies that the current atlas is a `dsh-pet` asset.
